BStoeq includes the unmodified 7-Zip 26.04 command-line engine (7zz),
Copyright (C) 1999-2026 Igor Pavlov. The macOS code-signing envelope is
updated for local application signing; the program code is not changed.

Related license terms are in 7-Zip.txt. The exact upstream source archive
7z2604-src.tar.xz is included here. It contains LGPL and other applicable
license texts. You may replace the standalone 7zz executable with a
compatible build of your choice; it is invoked as an external process.

Official download: https://www.7-zip.org/download.html
Binary: https://github.com/ip7z/7zip/releases/download/26.04/7z2604-mac.tar.xz
Source: https://github.com/ip7z/7zip/releases/download/26.04/7z2604-src.tar.xz

RAR compression uses an optional, separately installed user-supplied RAR
command-line program. No RARLAB compression binary or license is bundled.
BStoeq does not implement or reverse-engineer RAR compression.

BStoeq is an independent application, not affiliated with RARLAB or WinRAR.
